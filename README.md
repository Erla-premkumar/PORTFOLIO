# Erla Premkumar - Python Developer Portfolio

A modern, attractive, and fully responsive portfolio website built with HTML, CSS, and JavaScript.

## 📋 Setup Instructions

### 1. Add Your Profile Photo
- Save your professional profile photo as `profile.jpg` in the same folder as `index.html`
- Recommended dimensions: Square image (500x500px or larger)
- Supported formats: JPG, PNG

### 2. Files Included
- `index.html` - Main HTML file
- `styles.css` - All styling and animations
- `script.js` - Interactive features and animations
- `profile.jpg` - Your profile photo (add this)

## 🎨 Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #ec4899;
    --text-dark: #1f2937;
    --text-light: #6b7280;
    /* ... more colors ... */
}
```

### Content
Edit the HTML in `index.html` to update:
- Your name and contact information
- Skills and proficiency levels
- Projects and descriptions
- Education details
- Contact form

### Images
- Profile photo: Save as `profile.jpg` in the portfolio folder
- Project images: Can be added in the Projects section
